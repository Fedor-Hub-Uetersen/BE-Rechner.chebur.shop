# 🥖 BE-Rechner — Калькулятор Хлебных Единиц

Автономное веб-приложение (PWA) для быстрого и удобного расчёта Хлебных Единиц (BE / ХЕ), углеводов и дозировки инсулина. Разработано специально для людей с диабетом и их близких.

🌐 **Онлайн-версия:** [be-rechner.chebur.shop](https://be-rechner.chebur.shop/)

---

## ⚡ Основные возможности

* 🧮 **Быстрый расчёт ХЕ:** Мгновенная конверсия граммов углеводов в Хлебные Единицы.
* 📱 **PWA & Offline Mode:** Работает без интернета прямо в браузере и устанавливается как отдельное приложение на Android / iOS / ПК.
* 🌐 **Мультиязычность:** Полная поддержка русского (`RU`) и немецкого (`DE`) языков.
* 🌙 **Тёмная тема:** Удобный интерфейс в неоновом стиле, не напрягающий глаза.
* 🔒 **100% Конфиденциальность:** Все расчёты происходят исключительно на устройстве пользователя. Данные никуда не передаются.

---

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **PWA:** Web App Manifest, Service Worker
* **Hosting:** GitHub Pages + Nginx Reverse Proxy (VPS Hetzner)
